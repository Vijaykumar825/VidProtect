# User Manual

## Getting Started

### Creating an Account

1. Navigate to the application URL
2. Click **Register** in the navigation
3. Fill in the registration form:
   - **Username**: Choose a unique username
   - **Email**: Enter your email address
   - **Password**: Create a strong password (min 6 characters)
4. Click **Create Account**
5. You'll be automatically logged in and redirected to the dashboard

### Logging In

1. Click **Login** in the navigation
2. Enter your email and password
3. Click **Sign In**
4. You'll be redirected to your dashboard

---

## Dashboard

The dashboard provides an overview of your video library:

- **Total Videos**: Number of videos you've uploaded
- **Processing**: Videos currently being analyzed
- **Safe**: Videos classified as safe content
- **Flagged**: Videos flagged for sensitive content
- **Recent Videos**: Quick access to your latest uploads

---

## Uploading Videos

### Supported Formats
- MP4, MOV, AVI, MKV, WebM
- Maximum file size: 100MB

### Upload Process

1. Navigate to **Upload** in the sidebar
2. Click **Choose Video** or drag and drop a file
3. Enter a **Title** (required)
4. Add a **Description** (optional)
5. Click **Upload Video**
6. Monitor the upload progress bar
7. After upload, sensitivity analysis begins automatically

### Real-Time Processing

Once uploaded, videos go through sensitivity analysis:

1. **Processing Stage**: The system analyzes video content
2. **Progress Updates**: Live progress shown in real-time
3. **Completion**: Video receives classification (safe/flagged)

---

## Video Library

### Viewing Your Videos

Navigate to **Library** to see all your uploaded videos.

Each video card displays:
- Thumbnail (if available)
- Title
- Upload date
- File size
- Status (Processing/Completed/Failed)
- Classification (Safe/Flagged)

### Filtering Videos

Use the filter dropdown to show:
- **All Videos**: Complete library
- **Safe**: Only safe-classified videos
- **Flagged**: Only flagged videos
- **Processing**: Videos still being analyzed

### Sorting

Videos can be sorted by:
- Date (newest/oldest)
- Title (A-Z/Z-A)
- Size (largest/smallest)

## Managing Videos

2. Click **Delete** button

## User Roles

### Viewer
- Can view videos shared with them
- Cannot upload or delete videos

### Editor (Default for new users)
- Can upload new videos
- Can edit and delete own videos
- Full access to own video library

### Admin
- All editor permissions
- Access to Admin Panel
- Can manage all users
- Can modify user roles
- Can view all videos in the system

---

## Admin Panel

*Only visible to users with Admin role*

### Managing Users

1. Navigate to **Admin > Users**
2. View list of all registered users
3. Each user shows:
   - Username
   - Email
   - Current role
   - Registration date

### Changing User Roles

1. Find the user in the list
2. Click the role dropdown
3. Select new role (Viewer/Editor/Admin)
4. Role updates immediately

### Removing Users

1. Find the user to remove
2. Click the **Delete** button
3. Confirm deletion
4. User and their data are removed

## Troubleshooting

### Video Won't Upload

- Check file format (must be MP4, MOV, AVI, MKV, or WebM)
- Ensure file is under 100MB
- Check your internet connection
- Try refreshing the page

### Video Stuck in Processing

- Processing typically takes 30-60 seconds
- For larger files, it may take longer
- If stuck for more than 5 minutes, try refreshing
- Check the video status in the library

### Can't Play Video

- Ensure the video finished processing
- Check if video is classified (safe/flagged)
- Try a different browser
- Clear browser cache

### Login Issues

- Verify email and password are correct
- Check for caps lock
- Try the password reset option
- Clear browser cookies and retry

## Security Best Practices

1. **Use Strong Passwords**: Minimum 6 characters, mix of letters and numbers
2. **Don't Share Credentials**: Keep your login information private
3. **Log Out**: Always log out on shared computers
4. **Report Issues**: Contact admin if you notice suspicious activity
